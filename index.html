01 · Project Overview

A system built to make engagement mean something

The client runs a brand with two distinct audience segments — each with its own voice, demographic, and emotional relationship to the content. They had a high-volume social media presence and a team consistently replying to fan comments at scale.

The problem wasn't effort or volume. It was intelligence. Every fan comment was being processed manually with no retention, no buyer signal detection, and no data feeding back into content decisions. I designed and built MESI to close that gap — a browser-based AI system that turns fan engagement into a compounding strategic asset.

02 · The Challenge

Four problems the client didn't know they had

The existing workflow was consistent — but operating blind. The gaps weren't visible in daily operations; they showed up in suppressed reach, missed conversions, and a large content library that wasn't being used strategically.

Blanket CTA on every reply

The store link was added to every reply regardless of context. Emotional fan moments and genuine purchase-intent signals were treated identically — platforms flagged it as promotional spam and suppressed organic reach.

No behavioral memory

Thousands of comments processed weekly, zero data retained. No record of which content drove the most response, which post types generated purchase intent, or how engagement patterns shifted over time.

Two audiences, one undifferentiated voice

Both segments were served similar reply styles despite having meaningfully different demographics, emotional triggers, and relationships to the brand. Voice was inconsistent across the team.

Content decisions made by instinct

No data-driven content planning. The team couldn't answer: what to post next, when, and why? A large, rich content library sat as an untapped strategic resource.

03 · What I Built

Four modules. One shared intelligence layer.

MESI runs entirely in the browser — no server, no SaaS subscription, no installation. The architecture is modular: each component can be extended, rebranded, or redeployed independently for any brand or client.

Module 01 · Segment A

Reply Engine — Audience A

Generates on-brand fan replies for the first audience segment: younger, performance-driven, emotionally engaged. Detects buyer intent and inserts a store CTA only when genuine purchase signals are present in the comment.

Module 02 · Segment B

Reply Engine — Audience B

A fully separate voice for the second audience segment: faith-adjacent, nostalgic, older demographic. Same buyer-intent intelligence — entirely different tone, vocabulary rules, and conversational personality.

Module 03 · Planning

AI Strategy Engine

Reads the Memory Bank and generates Daily, Weekly, or Monthly content execution plans — with post types, caption directions, repurposing instructions, and content references sourced directly from the client's locked library.

Module 04 · Data

Behavioral Memory Bank

Every generated reply is stored and tagged automatically. Buyer signals are flagged and surfaced in a dedicated Conversion Tracker. Exports as JSON or a multi-sheet Excel workbook with cumulative history.

04 · Capabilities in Detail

Every component, explained

Dual-Voice Architecture
Two completely separate reply engines with distinct tones, vocabulary constraints, and audience assumptions. No voice bleed between segments. Each is tuned at the system-prompt level and operates independently.
Buyer Intent Detection
The system reads each comment for purchase signals — "where can I get this," "great gift," "want to own this" — and inserts the store link only when intent is clearly present. All other comments receive warmth-only replies, keeping the CTA ratio within platform-safe thresholds.
Memory Bank
Every generated reply is logged with timestamp, segment, post context, and engagement tag. Buyer signals are auto-flagged and pulled into a dedicated Conversion Tracker. Exports as JSON or Excel on demand.
Strategy Engine
Reads the full Memory Bank and generates content plans at three cadences. Each plan includes post type, platform, caption direction, repurpose source, fan comment attribution by actual stored username, and specific references sourced from the client's locked content library — never generic filler.
Content Library Lock
All content recommendations and plan references are pulled exclusively from the client's locked library of 600+ items. No hallucinated references. Every entry carries metadata: creator, collection, content type, and seasonal availability flag.
Seasonal Intelligence
Seasonally restricted content items are automatically excluded outside their eligible date window. Warnings surface in the UI. Strategy plans respect the filter with no manual input from the user.
Repurposing Engine
Execution plans enforce a minimum repurposed-content rule per posting period. The system recommends asset reuse, quote graphics, fan comment spotlights, and archival posts. No new content production required to maintain posting variety.
Excel Export (Cumulative)
Plans export to a 3-sheet workbook: full log, current period, and a periodic summary with repurpose ratios. Every run appends — nothing is overwritten. A clean, shareable record for any team member or stakeholder.
Archive System
Memory is archivable by date range (7 / 30 / 90 days) or by segment. Auto-exports before clearing — no data is permanently lost. A preview shows exact count and range before the action is confirmed.
Zero Infrastructure
Single HTML file. Runs in any browser. No server, no database, no accounts. Client supplies their own API key. All data is stored locally until exported. Complete ownership — no vendor dependency.

06 · Daily Workflow

How the system runs day-to-day

MESI fits into an existing social media workflow without replacing the human who hits post. The reply workflow takes minutes; the strategy engine runs on demand.

01

Paste the post context + fan comments

Select the audience segment tab, describe what was posted, paste the current store link, and copy in fan comments with @usernames from any platform. Hit Generate.

02

Review and copy replies

Each reply renders in the correct brand voice. Buyer-intent replies are flagged and include the CTA. One-click copy — no reformatting, no editing needed before pasting.

03

Memory builds automatically

Every reply is stored with segment, timestamp, and engagement tag. Buyer signals surface instantly in the Conversion Tracker. Nothing manual — no extra steps required.

04

Run the Strategy Engine on demand

Choose segment, choose period (Daily / Weekly / Monthly), add any campaign context. The engine reads the Memory Bank and returns a full posting plan referencing the client's actual content library and real stored fan usernames.

05

Export and execute

Download as Excel. Each row is an actionable post: date, platform, content type, caption direction, goal, repurpose source. Run. Repeat. Data compounds over time.
